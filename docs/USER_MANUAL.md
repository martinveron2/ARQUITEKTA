# USER MANUAL

## Inicio
La pantalla principal muestra proyectos, estados y módulos reutilizables.

## Nueva app
1. definir nombre y objetivo
2. elegir tipo de producto
3. seleccionar módulos
4. revisar arquitectura y Principio 0
5. crear proyecto

## Auditoría
Conectar un proyecto y ejecutar Auditoría MVA. ARQUITEKTA clasifica hallazgos en Cumple, Faltante, Desactualizado y Riesgo. Las correcciones automáticas siempre deben mostrar qué van a cambiar antes de aplicarse.
